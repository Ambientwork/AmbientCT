# Lightweight test-only dependency set for the Docker `test` build stage
# (plan §9 P2.1's explicit escape hatch: "darf der Agent für reine Unit-
# Tests einen zweiten leichten Requirements-Satz verwenden").
#
# Why this file exists (not just requirements.txt + requirements-dev.txt):
# torch/torchvision/nnunetv2 are heavy (CPU wheel download alone is
# hundreds of MB) and the unit test suite (ai-inference/tests/) never
# imports them at collection time — verified by grepping pipeline/*.py:
# `import torch` and the nnU-Net predictor import live inside
# pipeline/segmentation.py function bodies (lazy, real-inference-only code
# paths), not at module scope. No current test exercises those paths (see
# the `real_model` marker in pytest.ini for the category reserved for when
# they are). Skipping them keeps this stage fast to build.
#
# numpy==1.26.4 pinned to match requirements.txt exactly (both are bound
# by pydicom-seg==0.4.1's numpy>=1.18.0,<2.0.0), so this stage exercises a
# production-representative numpy major/version, not just a coincidentally
# compatible one.
#
# Consequence: this test stage does NOT install and does NOT exercise
# torch/nnunetv2/real inference. It must never be reported as a passed
# real-model or real-inference validation — only as what it is: the
# reproducible unit-test environment for demo-mode / mocked-predictor
# code paths.
